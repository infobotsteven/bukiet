# Bukiet Wspomnień - landing page

Makieta landing page wykonana w HTML + CSS + JavaScript.

## Uruchomienie
Otwórz `index.html` w przeglądarce.

## Struktura
- `index.html` - cała strona, CSS i JS
- `assets/` - logo oraz zdjęcia użyte w makiecie

Formularz zamówienia jest demonstracyjny i nie wysyła danych do backendu.
